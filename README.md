Made by Jacopo for all the Jacopos.

# Entities and Triggers

- Journal trigger: trigger that opens a journal showing the checkpoints of the level/map, their images and the collected red berries and the new entity untracked core berry

- Untracked core berry: It is built on the FrostHelper "Core Berry" and it makes it untracked (not displayed in the checkpoint selection menu), wow!
